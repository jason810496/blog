我自己是直接在 issue assign 給 Copilot 去做，或是自己做到一半在 review 時 @copilot 繼續往下做。
對於改 CI、測試、文件這類重複性高的工作，GitHub Coding Agent 的效果還不錯，能夠節省不少時間。

有些 one shot 就完成 90%，但蠻常最後 10% 怎麼跟他溝通自己想要的 fix/ final nits 他好像都理解不到位，我都會最後自己收尾。

好處是可以一次平行做很多 tasks 而且也不佔 local 資源，而且都是以 PR 的形式互動，跟平常在做 code review 的流程差不多。
